平台流程

由資格準備到雙方選聘

平台提供資訊及配對渠道，不代替資格認定、招聘面試或聘用合同。

資格資料確認

了解適用的任教資格、教育階段、科目及所需補充程序。

教師與學校登記

教師提供專業資料及意願；學校發布具體職位與聘用條件。

初步配對及面談

按職位條件提供參考資訊，雙方自行決定是否進一步洽談。

自行確認聘用

教師與學校確認合同、薪酬、工作時間、福利及其他安排。

資格銜接 正式資格及認可程序由有權限部門確認。
人力配對平台 連接教師專業資料與學校真實職位需求。
過渡性支援構想 政策文件提出研究有限期支援；本展示版不受理津貼申請。

常見問題

關於這個展示網站

這是真正的招聘平台嗎？

不是。這是展示介面及流程的前端原型，職位及人物資料均為虛構內容。

提交申請或職位後會發生甚麼？

按下按鈕只會顯示模擬提示，或在目前頁面暫時加入示範職位，不會傳送至伺服器。

能否在這裡確認教師資格？

不能。展示版不進行資格審查；資格認可和任教條件應以有權限部門的正式安排為準。

GitHub Pages 上的網站是公開的嗎？

公開 repository 發布的網站通常可供任何人瀏覽。不要在網站或 GitHub 檔案中加入真實個人資料或機密資訊。
